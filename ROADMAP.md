# Roadmap

## Phase 0 - Blueprint and UX Lock
- Confirm workflows, roles, policies, architecture, and data model.
- Create Employee Mobile, Head Approval, Finance Desktop, and Admin UX.
- Produce visual direction and high-fidelity mockups.
- Lock design system before implementation.

## Phase 1 - Core V1
- Entra ID login.
- Employee / organization.
- Leave.
- OT.
- Expense including Entertainment.
- Business Trip.
- Per Diem.
- Cash Advance and settlement.
- Approval engine.
- Finance verification.
- Receipt capture and original-receipt tracking.
- Petty cash payment batches.
- Payroll cycles and Easy-ACC export adapter.
- Smartbiz export adapter.
- Policy versioning.
- Audit trail.
- Responsive PWA.
- Docker Compose deployment on OCI.

## Phase 2 - Project and Automation Enhancement
- Microsoft Lists/SharePoint Project Master sync.
- Google Maps mileage automation.
- Project cost reporting.
- Teams notifications.
- Operational dashboards and finance reconciliation enhancements.

## Phase 3 - Convenience Integrations
- LINE OA rich menu.
- Deep links into PWA.
- Receipt Inbox via LINE.
- Additional automation around reminders and document intake.
- Advanced reporting and project profitability.
